Shorts Noticias

Ferramenta pessoal que publica, no canal de YouTube do seu autor, vídeos curtos (Shorts) com resumos de notícias do Brasil. Cada vídeo indica as fontes jornalísticas utilizadas.

A ferramenta usa os Serviços de API do YouTube apenas para enviar vídeos para o canal do próprio autor. Não é usada por outras pessoas e não recolhe dados de terceiros.
